Kebijakan Privasi (Privacy Policy)

Komitmen perlindungan data dan privasi pengguna aplikasi CATET: Financial & Mobility Intelligence.

Aplikasi: CATET v1.0.0
Pengembang: Luweng Studios
Status: Aktif & Berlaku Global
Diperbarui: September 2026

1 Prinsip Privasi & Arsitektur Offline-First

Luweng Studios menghormati hak privasi Anda sepenuhnya. CATET dibangun dengan filosofi dasar Offline-First & Zero-Knowledge Architecture. Seluruh data keuangan, transaksi kas, target tabungan, dan catatan log operasional Anda disimpan secara aman pada memori internal perangkat lokal Anda (SQLite / Room Database), dan TIDAK PERNAH dikirimkan ke server kami atau pihak mana pun.

Jaminan Bebas Komersialisasi: Kami tidak pernah menjual, menyewakan, atau menukar data pribadi, data lokasi, maupun catatan finansial Anda kepada pihak ketiga, broker data, atau biro periklanan mana pun.

2 Data yang Dikumpulkan & Tujuan Penggunaannya

Kami hanya mengakses data yang mutlak diperlukan untuk mengoperasikan fungsi utilitas yang diminta secara sadar oleh pengguna:

  • Autentikasi (Google Sign-In via Firebase Auth): Digunakan semata-mata untuk mengamankan identitas kepemilikan akun. Kami hanya menerima identitas profil publik dasar seperti Nama Lengkap, Alamat Email terdaftar, dan URL Foto Profil. Kami tidak dapat dan tidak pernah memiliki akses ke kata sandi Anda.
  • Izin Lokasi Presisi (GPS Coarse & Fine Location): Digunakan secara langsung saat Anda membuka fitur Radar BBM untuk menghitung jarak ke stasiun SPBU resmi terdekat, serta pada fitur Mode Mengemudi untuk kalkulasi speedometer dan akumulasi jarak perjalanan (KM). Koordinat GPS diproses secara matematis di perangkat Anda dan langsung dibuang tanpa disimpan ke server cloud.
  • Layanan Latar Belakang (Foreground Service): Saat Anda mengaktifkan Mode Mengemudi atau Widget Speedometer Mengambang, sistem menjalankan Foreground Service dengan notifikasi persisten agar aplikasi dapat terus mencatat jarak tempuh secara akurat saat layar redup atau saat Anda menggunakan aplikasi navigasi lain. Layanan ini sepenuhnya berada di bawah kendali Anda dan dapat dimatikan kapan saja.
  • Izin Notifikasi (Android 13+ POST_NOTIFICATIONS): Digunakan untuk menampilkan indikator berkendara aktif serta menyampaikan Pengingat Servis Berkala (seperti ganti oli mesin, oli gardan, atau servis rantai/CVT) berdasarkan ambang batas Odometer. Evaluasi servis dilakukan 100% di perangkat Anda tanpa pelaporan ke server luar.

3 Keamanan Cadangan Data (Backup & Encryption)

CATET menyediakan fitur pencadangan data independen:

  • Format Cadangan CTT Terenkripsi: File cadangan (.ctt) dienkripsi menggunakan algoritma standar industri dengan salt unik perangkat Anda. File ini sepenuhnya berada dalam kepemilikan Anda untuk disimpan di memori HP atau dibagikan ke penyimpanan pribadi Anda.
  • Sinkronisasi Google Drive Opsional: Jika Anda mengaktifkan fitur pencadangan cloud, data disimpan langsung di Google Drive milik akun Anda sendiri. Luweng Studios tidak memiliki perantara server dan tidak memiliki akses terhadap file cadangan Anda.

4 Layanan Pihak Ketiga

Aplikasi CATET menggunakan dependensi infrastruktur resmi Google untuk memastikan kestabilan dan keamanan aplikasi:

  • Google Play Services: Untuk penyediaan Fused Location Provider berakurasi tinggi.
  • Google Firebase Authentication: Untuk otentikasi login aman Single Sign-On (SSO).

Kedua layanan tersebut tunduk pada kebijakan privasi resmi Google LLC (Google Privacy Policy).

5 Hak Pengguna & Penghapusan Data (Right to Erasure)

Sesuai dengan standar perlindungan data global (GDPR) dan Undang-Undang Perlindungan Data Pribadi (UU PDP Indonesia), Anda memiliki kendali penuh:

  • Penghapusan Seketika: Anda dapat menghapus seluruh catatan transaksi, profil, dan histori log melalui tombol Hapus Semua Data di dalam aplikasi, atau melalui menu Hapus Penyimpanan / Clear Storage di Pengaturan HP Anda.
  • Pencabutan Izin: Izin lokasi, notifikasi, dan overlay dapat dicabut kapan saja melalui menu Setelan Aplikasi di perangkat Android Anda.
